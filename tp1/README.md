# TP1 — Le squelette d'ExploMonde

**Objectif :** un `index.html` sémantique, valide W3C, sans une seule ligne de CSS.

## Ce qui est fait
- Arborescence de projet créée (`tp1/index.html`).
- `header` avec `h1` + `nav`, `main`, `footer`.
- `main` contient une section de recherche (`h2` + champ + bouton) et une section de résultats (`h2`).
- 3 articles de démonstration : nom du pays, capitale, région, population (liste `dl`).
- Aucun CSS.

## Validation W3C (en autonomie)
1. Ouvrir https://validator.w3.org/#validate_by_upload
2. Uploader `tp1/index.html`.
3. Corriger jusqu'à **0 erreur** (les *warnings* « lang » et « landmark » seront traités au TP2).
4. Enregistrer la capture d'écran ici : `tp1/capture-validateur.png`

## Livrable
- `tp1/index.html` valide
- `tp1/capture-validateur.png`
